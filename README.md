# Portfólio profissional — Breitner Maquito

Projeto independente do repositório Tinight.github.io. HTML e CSS estáticos, sem instalação de dependências, fontes remotas, rastreamento ou coleta de dados.

## Arquivos e edição

- `index.html`: apresentação, caso Aura, seção futura de Power BI e LinkedIn.
- `styles.css`: cores, layout, responsividade e foco visível.
- `docs/revisao-demonstracao.md`: avaliação do destino Typebot e pendências para publicação.

Abra `index.html` no navegador ou execute `python -m http.server 8766` nesta pasta e visite http://127.0.0.1:8766/. Links relativos permitem futura hospedagem em /portfolio/.

## Estado

Prévia para aprovação; GitHub Pages não deve ser ativado antes da aprovação explícita. Criar ou armazenar o código no GitHub não publica o site.

## Aura

As funcionalidades descritas são demonstrações, sem agendamento real, CRM externo ou parceria comercial. Não incluímos logotipos de fabricantes ou projetos privados. Os elementos visuais de fluxo são decorativos e não representam uma captura do chatbot.

O acesso externo não está ativo nesta versão porque o demonstrativo possui coleta de telefone e apresentação que precisa de revisão. Consulte a avaliação antes de disponibilizá-lo. Não há número, formulário ou token neste código.
